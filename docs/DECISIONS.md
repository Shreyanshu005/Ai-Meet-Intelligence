# Architectural Decisions

## JWT Auth
- **Choice**: JWT
- **Why**: Stateless authentication that can scale seamlessly without maintaining session store state.
- **Alternatives**: Session-based auth with Redis or memory store.
- **Trade-offs**: JWT revocation requires a blocklist implementation if immediate revocation is needed, but simplifies the backend.

## ORM
- **Choice**: Prisma
- **Why**: Type safety guarantees, autogenerated TypeScript client, intuitive schema, and seamless schema migrations.
- **Alternatives**: TypeORM, Sequelize, or raw SQL queries with pg.
- **Trade-offs**: Slightly larger bundle size and memory overhead, but development velocity is highly improved.

## Database
- **Choice**: PostgreSQL
- **Why**: Powerful relational model with excellent support for JSON columns (used to store citations and transcripts), and reliable transaction support.
- **Alternatives**: MongoDB (NoSQL), MySQL.
- **Trade-offs**: Requires rigid schemas and migrations, but ensures data consistency and integrity for related entries like meetings and action items.

## Email / Notifications
- **Choice**: Resend
- **Why**: Extremely simple SDK, generous free tier, professional reliability, 5-minute integration.
- **Alternatives**: SendGrid, AWS SES, Nodemailer with SMTP.
- **Trade-offs**: Locked into a specific provider's API compared to standard SMTP, but much faster to integrate.

## Caching
- **Choice**: Redis
- **Why**: AI analysis calls are expensive and slow. Caching ensures repeated requests return instantly and prevents API abuse.
- **Alternatives**: In-memory caching (like node-cache).
- **Trade-offs**: Requires another infrastructure component to host and manage, but guarantees scalable caching even across multiple instances.

## LLM Provider
- **Choice**: Groq (llama-3.3-70b-versatile)
- **Why**: Chosen for its ultra-low latency inference (typically <1s for 70B models), generous free tier, and native json_object response format which eliminates output parsing failures. llama-3.3-70b-versatile was selected over smaller models for its instruction-following accuracy on structured extraction tasks.
- **Alternatives**: Anthropic (Claude), OpenAI (GPT-4o).
- **Trade-offs**: Less deterministic than fine-tuned models for edge-case transcripts, mitigated by temperature=0.1 and programmatic citation validation.
